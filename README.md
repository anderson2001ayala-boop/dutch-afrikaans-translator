# 🌍 Traductor Neerlandés → Afrikáans

Proyecto de inteligencia artificial en Python que traduce textos automáticamente usando Deep Translator.

## 🚀 Funciones

- Traducción automática de archivos TXT
- Procesamiento por lotes
- Exportación de resultados
- Generación de reportes CSV
- Estadísticas de texto

## 🛠️ Tecnologías

- Python
- Deep Translator
- Pandas
